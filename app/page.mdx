# theme-memories/argon2

Argon2 verification module

## Endpoint

<Card title="/api/verify" badge={{ label: "POST" }}>
  Verifies a password against an Argon2 hash. Designed for server-to-server
  communication. The endpoint runs on Node.js and does not cache responses.
</Card>

## Required Configuration

Set these values in Vercel:

| Variable                   | Purpose                                                               |
| -------------------------- | --------------------------------------------------------------------- |
| `ED25519_PUBLIC_KEY`       | Base64url-encoded SPKI DER public key used to verify Worker requests. |
| `UPSTASH_REDIS_REST_URL`   | Upstash HTTPS REST URL for one-time nonce storage.                    |
| `UPSTASH_REDIS_REST_TOKEN` | Upstash REST authentication token.                                    |

The WAF service token is configured separately in the Cloudflare Worker and
Vercel WAF. It is not read by application code.

## Authentication

<Card title="Ed25519 Request Signature">
  Every request is authenticated with an Ed25519 signature. The Cloudflare
  Worker keeps the private key; this application stores only the base64url
  encoded public key in `ED25519_PUBLIC_KEY`.

The Worker signs the exact bytes of `timestamp`, `nonce`, and the raw request
body, separated by newlines:

```text
<unix-timestamp>\n<uuid-v4-nonce>\n<raw-json-body>
```

Timestamps must be within 60 seconds of server time. Each valid nonce is
accepted once and stored in Upstash Redis for 120 seconds. Requests with a
reused nonce return `errcode: 6`. Redis failures fail closed with
`errcode: 5`.

</Card>

## Request & Response

<CardGrid>
  <Card title="Request Body">

```json showLineNumbers
{
  "user_input": "password",
  "stored_hash": "$argon2id$..."
}
```

`user_input` must be 5-128 characters from `A-Z a-z 0-9 !@#$%^&*`.
The raw request body must be no larger than 1024 bytes. Requests must be `POST`
with `Content-Type: application/json`. The body must be signed before sending;
do not parse and reserialize it after signing.

  </Card>

## WAF Bypass Token

<Card title="X-Service-Token Header">
  For legitimate server-to-server traffic, include an `X-Service-Token` header.
  Configure Vercel WAF custom rules in this order: block, rate limit, then
  bypass. The bypass rule is evaluated after the preceding protections, so the
  token does not override a matching block or an earlier rate-limit rule.

```http
X-Service-Token: your-service-token-here
```

Keep the token secret. Anyone holding it may satisfy the bypass rule, though
Ed25519 request authentication still applies.

</Card>

## Example Usage

<Card title="Astro on Cloudflare">

```jsonc showLineNumbers
// wrangler.jsonc
{
  "secret_store_bindings": [
    { "binding": "ED25519_PRIVATE_KEY", "store_id": "your-secret-store-id" },
    { "binding": "SERVICE_TOKEN", "store_id": "your-secret-store-id" },
  ],
}
```

Generate the Worker secret from the same Ed25519 key pair. Store the base64url
encoded PKCS8 DER private key in `ED25519_PRIVATE_KEY`; store the SPKI DER
public key in Vercel as `ED25519_PUBLIC_KEY`:

```sh
openssl genpkey -algorithm ED25519 -out ed25519-private.pem
openssl pkcs8 -topk8 -nocrypt -in ed25519-private.pem -outform DER | base64 -w0 | tr '+/' '-_' | tr -d '='
openssl pkey -in ed25519-private.pem -pubout -outform DER | base64 -w0 | tr '+/' '-_' | tr -d '='
```

```typescript showLineNumbers
// src/pages/api/auth.ts
import type { APIRoute } from "astro";
import { env } from "cloudflare:workers";

export const prerender = false;

export const POST: APIRoute = async ({ request }) => {
  const { password, slug } = await request.json();
  const row = await env.DB.prepare(
    "SELECT password_hash FROM vault WHERE slug = ?",
  )
    .bind(slug)
    .first<{ password_hash: string }>();

  if (!row?.password_hash) {
    return new Response("Not found", { status: 404 });
  }

  const privateKeyBase64 = await env.ED25519_PRIVATE_KEY.get();
  const serviceToken = await env.SERVICE_TOKEN.get();
  const body = JSON.stringify({
    user_input: password,
    stored_hash: row.password_hash,
  });
  const timestamp = String(Math.floor(Date.now() / 1000));
  const nonce = crypto.randomUUID();
  const signedBytes = new TextEncoder().encode(
    `${timestamp}\n${nonce}\n${body}`,
  );
  const privateKey = await crypto.subtle.importKey(
    "pkcs8",
    decodeBase64Url(privateKeyBase64),
    { name: "Ed25519" },
    false,
    ["sign"],
  );
  const signature = toBase64Url(
    new Uint8Array(
      await crypto.subtle.sign("Ed25519", privateKey, signedBytes),
    ),
  );
  const response = await fetch("https://example.com/api/verify", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-Request-Timestamp": timestamp,
      "X-Request-Nonce": nonce,
      "X-Request-Signature": signature,
      "X-Service-Token": serviceToken,
    },
    body,
  });

  return response;
};

function decodeBase64Url(value: string): Uint8Array {
  const base64 = value.replaceAll("-", "+").replaceAll("_", "/");
  const padded = base64 + "=".repeat((4 - (base64.length % 4)) % 4);
  const binary = atob(padded);
  return Uint8Array.from(binary, (character) => character.charCodeAt(0));
}

function toBase64Url(value: Uint8Array): string {
  let binary = "";
  for (const byte of value) binary += String.fromCharCode(byte);
  return btoa(binary)
    .replaceAll("+", "-")
    .replaceAll("/", "_")
    .replaceAll("=", "");
}
```

## API Smoke Test

Run the local script to send one signed verification request. It generates a
temporary password and Argon2 hash in memory, prompts for secrets without
writing them to disk, and never prints the password, hash, or private key:

```sh
pnpm test:api
```

The script prompts for the endpoint URL, WAF service token, and base64url
encoded PKCS8 Ed25519 private key. It exits non-zero unless the API returns
`success: true` with `errcode: 0`.

## Argon2 Parameters

<Card title="OWASP Recommended">
  Uses Argon2id with OWASP minimum parameters: `m=19456` (19 MiB), `t=2`, `p=1`.
  Hashes whose parameters do not match exactly are rejected with `errcode: 7`
  (HTTP 422) before verification runs, so non-standard parameters cannot be used
  to drain CPU.
</Card>
