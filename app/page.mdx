# theme-memories/argon2

Argon2 verification module

## Endpoint

<Card title="/api/verify" badge={{ label: "POST" }}>
  Verifies a password against an Argon2 hash. Designed for server-to-server
  communication.
</Card>

## Example Usage

<Card title="Cloudflare Worker">

```typescript showLineNumbers
// Cloudflare Worker (server-to-server)
const response = await fetch("https://nextjs.vercel.app/api/verify", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    user_input: password,
    stored_hash: hashFromDB,
  }),
});

const { success, errcode } = await response.json();
```
