# theme-memories/argon2

Argon2 verification module

## Endpoint

<Card title="/api/verify" badge={{ label: "POST" }}>
  Verifies a password against an Argon2 hash. Designed for server-to-server
  communication.
</Card>

## Authentication

<Card title="X-API-Key Header">
  All requests must include an `X-API-Key` header with a valid API key. The
  comparison uses constant-time algorithm to prevent timing attacks.

```http
X-API-Key: your-api-key-here
```

</Card>

## Request & Response

<CardGrid>
  <Card title="Request Body">

```json showLineNumbers
{
  "user_input": "password",
  "stored_hash": "$argon2id$..."
}
```

`user_input` must be 5-128 characters from `A-Z a-z 0-9 !@#$%^&*`.
Requests must be `POST` with `Content-Type: application/json`.

## WAF Bypass Token

<Card title="X-Service-Token Header">
  To bypass rate limiting for legitimate server-to-server traffic, include an
  `X-Service-Token` header. Configure a Vercel WAF custom rule to match this
  header and apply the `bypass` action.

```http
X-Service-Token: your-service-token-here
```

A matching request skips Firewall evaluation entirely — both bot protection
and rate limiting. This is what allows non-browser Worker traffic to pass.
Keep the token secret: anyone holding it bypasses these protections, though
application-level API key authentication still applies.

</Card>

## Example Usage

<Card title="Astro on Cloudflare">

```jsonc showLineNumbers
// wrangler.jsonc
{
  "secret_store_bindings": [
    { "binding": "API_KEY", "store_id": "your-secret-store-id" },
    { "binding": "SERVICE_TOKEN", "store_id": "your-secret-store-id" },
  ],
}
```

```typescript showLineNumbers
// src/pages/api/auth.ts
import type { APIRoute } from "astro";
import { env } from "cloudflare:workers";

export const prerender = false;

export const POST: APIRoute = async ({ request }) => {
  const { password, slug } = await request.json();
  const row = await env.DB.prepare(
    "SELECT password_hash FROM vault WHERE slug = ?",
  )
    .bind(slug)
    .first<{ password_hash: string }>();

  if (!row?.password_hash) {
    return new Response("Not found", { status: 404 });
  }

  const apiKey = await env.API_KEY.get();
  const serviceToken = await env.SERVICE_TOKEN.get();
  const response = await fetch("https://example.com/api/verify", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-API-Key": apiKey,
      "X-Service-Token": serviceToken,
    },
    body: JSON.stringify({
      user_input: password,
      stored_hash: row.password_hash,
    }),
  });

  return response;
};
```

## Argon2 Parameters

<Card title="OWASP Recommended">
  Uses Argon2id with OWASP minimum parameters: `m=19456` (19 MiB), `t=2`, `p=1`.
  Hashes whose parameters do not match exactly are rejected with `errcode: 3`
  (HTTP 500) before verification runs, so non-standard parameters cannot be used
  to drain CPU.
</Card>
